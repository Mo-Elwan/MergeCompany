وثيقة المتطلبات والمعمارية التنفيذية: تصحيح أوضاع ونقل تراخيص السجلات التجارية الفرعية

تحليل معماري شامل لحوكمة نقل وربط التراخيص والخدمات الزراعية والبيئية بعد إلغاء مفهوم السجلات الفرعية، مع حظر السجل الفرعي، إيقاف مفوضيه، واستكمال معالجة الطلبات الجارية لمفوضي الكيان الجديد.

الدمج في السجل الرئيسي لا يتطلب موافقة الوزارة لأن الرقم الموحد (700) واحد، بينما تأسيس شركة جديدة ينشئ كياناً جديداً برقم (700) مستقل يستلزم موافقة الوزارة الإلزامية.

المقدمة ونطاق العمل والأهداف

نطاق العمل والأهداف التشغيلية
المرجع: قرار 288

بناءً على التوجيهات الوزارية المنظمة للقرار الوزاري رقم (288) الصادر من وزارة التجارة بشأن إلغاء مفهوم السجلات التجارية الفرعية وحصر خيارات المنشآت في تصحيح أوضاعها، يهدف هذا الحل المعماري في منظومة خدمات منصة "نما" بوزارة البيئة والمياه والزراعة إلى معالجة كافة الآثار التشغيلية والقانونية على التراخيص والموافقات والخدمات والطلبات الجارية.

أتمتة وحوكمة النقل

تمكين نقل التراخيص الصادرة إلكترونياً وفق المسار المناسب دون تأخير الأعمال الزراعية والبيئية القائمة.

الحفظ التام للحجية

حفظ سجل تاريخي غير قابل للمسح أو التعديل لجميع الشهادات وتقارير الرقابة الصادرة تحت السجل الفرعي سابقاً.

استمرار المعاملات الجارية

ضمان عدم تعطل الطلبات التي تحت المعالجة (مثل شهادة سعودي قاب) وتحويلها لمفوضي الكيان الجديد لاستكمالها.

المعمارية الوظيفية وسير العمل في منصة "نما"

دورة عمل الخدمة الإلكترونية المتكاملة
4 خطوات تنفيذية
1 التحقق المسبق من سياق الحساب:
سجل فرعي فقط

يتعرف النظام تلقائياً على السجل التجاري المفتوح بالجلسة ويشترط أن يكون سجلاً فرعياً. يمنع النظام فتح الخدمة إذا كان السجل رئيسياً. تعرض الشاشة بيانات السجل واسم الشركة الأم دون أي خيار منسدل لاختيار السجل.

2 التحقق من تسجيل الكيان ومطابقة الأنشطة الاقتصادية:
مطابقة الأنشطة المعتمدة

يتحقق النظام آلياً من تسجيل السجل المستهدف (الرئيسي أو الشركة الجديدة) وتفعيله في منصة نما، ويمنع التقدم في حال عدم وجوده. كما يعرض قائمة الأنشطة الاقتصادية (للعرض فقط) مع إجراء مطابقة آلية إلزامية للتأكد من شمول السجل المستهدف لأنشطة التراخيص المطلوب نقلها.

3 موافقة واعتماد المفوض النظامي:
مرحلة الاعتماد الأولية

في مسار الدمج: يوافق مفوض السجل الرئيسي ويتم النقل فورياً. في مسار الشركة الجديدة: تحال المعاملة إلى صندوق وارد مفوض الشركة الجديدة للموافقة الرسمية وتوثيق التاريخ والوقت بالثانية قبل الرفع للوزارة.

4 شاشة تدقيق وقرار موظف الوزارة:
خيارات القرار الثلاثية

تظهر لموظف الوزارة شاشة كاملة متضمنة بيانات السجلين، التراخيص، مطابقة الأنشطة، وتوثيق موافقة مفوض الشركة الجديدة مع التاريخ والوقت، وحقل كتابة الملاحظات مع 3 خيارات قطعية: (قبول الطلب / إرجاع الطلب لمقدمه لاستكمال النواقص / رفض الطلب).

4

مصفوفة معالجة الأصول والطلبات بجميع حالاتها

دورة حياة الأصول والمعاملات وحالاتها
شاملة للطلبات الجارية
نوع الأصل / المعاملة الحالة التشغيلية المعالجة الفنية والإجرائية في النظام النتيجة النهائية للمستفيد
التراخيص والموافقات الصادرة سارية ونشطة تحديث حقل السجل التجاري ورمز التحقق الرقمي السريع وإصدار وثيقة رقمية محدثة. تظهر فوراً في لوحة تحكم السجل الجديد/الرئيسي.
الطلبات قيد الإجراء (مثل: شهادة سعودي قاب) قيد المعالجة تُنقل ملكية المعاملة إلى السجل المستهدف، ويُمنح مفوضو الكيان الجديد صلاحية الرد على النواقص ومتابعتها. تستمر المعاملة دون انقطاع ويصدر الترخيص باسم الكيان الجديد.
الطلبات قيد التفتيش والزيارة الميدانية قيد التفتيش تظل الزيارة قائمة على الموقع الجغرافي الفعلي، ويتابع المفتش مع مفوضي الشركة الجديدة. توثيق محضر التفتيش باسم الكيانين معاً.
الطلبات بمرحلة سداد الفاتورة المالية بانتظار السداد تظل فاتورة سداد سارية الصلاحية برقمها المالي دون إلغاء، وتتاح لمفوضي الكيان الجديد. بمجرد السداد يُصدر الترخيص باسم السجل الجديد.
التراخيص المنتهية أو الملغاة سابقاً منتهية / ملغاة تُنقل إلى تبويب "الأرشيف التاريخي" ولا تُرحل كتراخيص نشطة. للاطلاع فقط مع حفظ كامل السجلات والمخالفات السابقة.
التقديم على خدمات جديدة تماماً طلب جديد يمنع النظام تقديم أي طلب جديد على أي سجل فرعي مشطوب. حظر قطعي وإجبار على التقديم بالسجل الجديد.

حوكمة الحظر وتجميد المفوضين وانتقال الصلاحيات

إجراءات الحظر وإيقاف المفوضين ونقل المعاملات
إجراءات أمنية فورية
⚠️
قاعدة الأثر الفوري فور صدور الموافقة: تُطبق الإجراءات الثلاثية التالية آلياً وبصورة متزامنة بمجرد موافقة مفوض السجل الرئيسي (في مسار الدمج) أو صدور قرار قبول موظف الوزارة (في مسار تأسيس شركة جديدة).
🔒

1. حظر التعامل على السجل الفرعي

  • • تحويل حالة السجل إلى: محظور ومدمج نهائياً.
  • • منع إنشاء أي معاملة أو تقديم جديد نهائياً.
  • • إظهار إشعار مانع يوضح انتقال التراخيص للكيان البديل.
🚫

2. إيقاف وتجميد جميع المفوضين

  • • تعطيل وإيقاف كافة صلاحيات الارتباط فورياً (موقوف بسبب الدمج).
  • • إسقاط السجل نهائياً من قائمة المنشآت النشطة وحسابات المفوضين.
  • • إبطال أي صلاحيات توقيع أو مسودات غير مرسلة.
⚡

3. تمكين مفوضي الكيان الجديد

  • • نقل المعاملات الجارية (مثل شهادة سعودي قاب #99014).
  • • صلاحية استكمال الرد على النواقص ورفع المستندات.
  • • سداد فواتير سداد ومرافقة التفتيش واستلام الترخيص.

استراتيجية الاحتفاظ بالبيانات والتتبع التاريخي

التتبع والتوثيق التاريخي والتحقق الرقابي
حفظ الحجية القانونية
سياسة الحظر التام للحذف النهائي للبيانات:

يحظر معمارياً حذف أو الكتابة فوق بيانات السجل التجاري الفرعي المنقول منه؛ حيث يتم الاحتفاظ برقم الترخيص الوطني أو رقم التسجيل كرقم وطني ثابت غير قابل للتغيير، مع تحديث مرجع المنشأة المالكة وتوثيق الحركة في سجل التتبع.

شاشة التحقق عند مسح الرمز الرقمي (الباركود الذكي) للمفتشين:

عند قيام مفتش الوزارة بمسح الباركود لأي ترخيص أو شحنة زراعية سابقة، يظهر له بيان نظامي: "الترخيص حالياً تابع للشركة الجديدة رقم (1010998877) والرقم الموحد (7002998114)، وكان مقيداً سابقاً على السجل الفرعي المشطوب رقم (1010345678) قبل تصحيح الوضع بتاريخ 1448/03/22هـ بموجب القرار الوزاري رقم 288".

نموذج قاعدة البيانات والعمليات الآلية المطبقة

Relational Data Model & Post-Approval SQL Triggers 
-- 1. جدول تسجيل ومتابعة طلبات التصحيح
CREATE TABLE CR_Correction_Requests (
    Request_ID VARCHAR(30) PRIMARY KEY,
    Source_CR_Number VARCHAR(20) NOT NULL,          -- رقم السجل الفرعي القديم
    Target_CR_Number VARCHAR(20) NOT NULL,          -- رقم السجل المستهدف (الرئيسي/الجديد)
    Unified_National_Number VARCHAR(20),            -- الرقم الموحد 700
    Correction_Type ENUM('MERGE_MAIN', 'NEW_COMPANY') NOT NULL, 
    Status ENUM('SUBMITTED', 'APPROVED_BY_DELEGATE', 'APPROVED', 'REJECTED', 'RETURNED') DEFAULT 'SUBMITTED',
    Approver_Delegate_National_ID VARCHAR(20),
    Delegate_Approval_Date TIMESTAMP NULL,
    Reviewer_User_ID VARCHAR(50),
    Review_Comments TEXT,
    Approval_Date TIMESTAMP NULL,
    Created_At TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. جدول تتبع حركة الأصول وتاريخ التراخيص
CREATE TABLE Asset_Transition_Audit (
    Audit_ID BIGINT AUTO_INCREMENT PRIMARY KEY,
    Request_ID VARCHAR(30) NOT NULL,
    Asset_Type ENUM('LICENSE', 'REGISTRATION', 'IN_PROGRESS_REQUEST', 'PERMIT') NOT NULL,
    Asset_Identifier VARCHAR(50) NOT NULL,          -- رقم الترخيص أو المعاملة (مثل: #99014)
    Old_CR_Number VARCHAR(20) NOT NULL,
    New_CR_Number VARCHAR(20) NOT NULL,
    Transition_Status ENUM('SUCCESS', 'FAILED') DEFAULT 'SUCCESS',
    Transition_Date TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (Request_ID) REFERENCES CR_Correction_Requests(Request_ID)
);

-- 3. حزمة العمليات الآلية المنفذة فور صدور قرار الاعتماد النهائي:
-- أ) حظر التعامل على السجل الفرعي فورياً:
UPDATE CR_Accounts 
SET Account_Status = 'BLOCKED_MERGED', 
    Blocked_Reason = 'Consolidated into Target CR pursuant to Commerce Decision No. 288',
    Blocked_Date = CURRENT_TIMESTAMP 
WHERE CR_Number = :Source_CR_Number;

-- ب) إيقاف وتجميد صلاحيات كافة المفوضين على السجل الفرعي:
UPDATE User_Delegations 
SET Delegation_Status = 'SUSPENDED_BY_MERGER', 
    Revocation_Date = CURRENT_TIMESTAMP,
    Revocation_Reason = 'Branch CR Merged / Liquidated'
WHERE CR_Number = :Source_CR_Number;

-- ج) نقل وتوجيه الطلبات الجاري معالجتها إلى مفوضي السجل الجديد للاستكمال:
UPDATE Service_Requests 
SET CR_Number = :Target_CR_Number,
    Delegation_Group = 'TARGET_CR_DELEGATES',
    Updated_At = CURRENT_TIMESTAMP
WHERE CR_Number = :Source_CR_Number 
  AND Request_Status IN ('UNDER_REVIEW', 'PENDING_APPLICANT', 'INSPECTION_SCHEDULED', 'PENDING_PAYMENT');
